The emoji:

> 🤗

A hugging face — an open-armed hug aimed at a stranger. Warm at first glance, universal, instantly readable, and chosen rather than the default smiley.

`main.py` validates the entry (exactly one emoji, 1–8 characters, not blank) and writes it to `entry.txt` in `$MAKEFUN_OUTPUT_DIR` (default `/output`).
